# 预测引擎设计 + 期权策略 + 风控

系统 C 层（预测引擎）和 D 层（期权策略）的详细设计文档。

---

## 一、层级时间结构

预测采用 **三级时间框架**，上级约束下级：

| 层级 | 频率 | 作用 | 决策内容 |
|------|------|------|----------|
| 月线层 | 月频 | 大方向锚定 | 宏观 Regime (多头/空头/震荡环境) |
| 周线层 | 周频 | 波段方向 | 中期趋势确认，波段目标位 |
| 日线层 | 日频 | 精确择时 | 入场/出场时机，期权到期日选择 |

**核心原则**：
- 月线决定多空倾向 — 月线看多则以做多为主，看空时不做空（风险不对称）
- 周线决定波段节奏 — 波段小方向可以与月线不同，但仓位受月线约束
- 日线决定交易执行 — 精确入场/出场时机

**不做日内超短线**，但也不做超长周期。运行频率为每隔数小时一次。

## 二、预测引擎详细设计

### 2.1 宏观锚定模块 (Macro Anchor)

继承中金黄金定价模型思路，升级为非线性 + Regime 切换。

| 项目 | 内容 |
|------|------|
| **输入因子** | 美债10年实际收益率(DFII10), 10年通胀预期(T10YIE), 美元指数(DXY), 央行购金(WGC月度), 联邦债务(GFDEBTN), 财政赤字(MTSDS133FMS), CPI(CPIAUCSL), M2(M2SL), 贸易加权美元(DTWEXBGS) |
| **输出** | (a) 黄金公允价值偏离度 (b) 宏观Regime分类 |
| **模型路线** | V1: 线性回归(基线) + XGBoost -> V2: 状态切换模型 |
| **频率** | 月频/季频更新 |

为什么要做 Regime 切换：黄金与实际利率的负相关性在长期并不稳定（中金 2025 版也因此剔除了利率因子），WGC 研究也确认不同阶段因子重要性不同。Phase 3 基线结果也验证了这一点：Ridge 在 2024-2025 金价暴涨期完全失效，而 XGBoost 相对更稳健。

### 2.2 公允价值区间模块 (Fair Value Band)

**设计转变**：Phase 3 基线验证表明，点预测 (fwd_ret_5d/10d/20d) 虽有 IC 但方向策略跑不赢 Buy & Hold，且线性模型在 regime shift 期间完全失效。因此从"预测未来收益率"转向"判断当前价格是否偏离公允区间"。

**核心方法**：分位数回归 (Quantile Regression)
- `sklearn.linear_model.QuantileRegressor` — 线性版，L1 正则化
- `xgboost` with `objective='reg:quantile'` — 非线性版，捕捉 regime 变化

| 项目 | 内容 |
|------|------|
| **输入因子** | 宏观因子(DFII10, T10YIE, DXY, 央行购金, 联邦债务等) + 全部 116 特征(技术+波动率+COT) |
| **输出** | 条件分位数: fair_value_q10 / q25 / q50 / q75 / q90 (GLD 价格水平) |
| **模型矩阵** | CICC 4-Factor (分位数扩展), Ridge Full (116特征), XGBoost Full (116特征), Ensemble |
| **频率** | 日频 |

**输出解读**：
- 价格 < q10: 极度低估，强做多信号
- 价格在 q10-q25: 温和低估，做多信号
- 价格在 q25-q75: 公允价值区间内，无明确方向信号
- 价格在 q75-q90: 温和高估，减仓或观望
- 价格 > q90: 极度高估，警惕回调

**评估指标**：Coverage Rate (目标~80%), Band Width, Calibration Error, Edge-Touch Reversion Rate

**Phase 3 基线验证结论（仍然有效）**：
- 长周期信号更强：ret_20d IC (0.21) 远高于 ret_5d IC (0.08)，偏好 20-30 DTE 期权
- 宏观因子 (real_yield_10y) 是收益率最强预测因子
- XGBoost top 特征: gvz_high, vix_backwardation, m2_yoy, federal_debt, copper_gold_ratio
- Ridge 在 2024-2025 regime shift 期间失效，XGBoost 相对更稳健 → 分位数回归中 XGBoost 版本尤为重要

### 2.3 波动率预测模块 (Volatility Forecast)

期权交易的核心 — 方向看对但 IV 塌了一样亏钱。

| 项目 | 内容 |
|------|------|
| **输入因子** | GLD 历史波动率(多窗口 5/10/20/60D), GVZ(黄金IV指数), VIX期限结构(VIX/VIX9D/VIX3M/VIX6M), MOVE(债券波动率), 期权IV曲面(Moomoo), 经济事件日历(FOMC/NFP/CPI前窗口) |
| **输出** | 未来实现波动率预测, IV 相对历史分位数的偏离判断, 大行情触发概率 |
| **模型路线** | V1: GARCH族(基线) -> V2: 深度学习增强 |
| **频率** | 日频 |

**GVZ 指数是关键变量** — 它是 CBOE 基于 GLD 期权报价构造的黄金波动率指数，比历史波动率更灵敏，能反映市场对未来波动的"报价情绪"。

**iv_rv_spread 口径定义**：
- `iv_rv_spread = GVZ/100 - fwd_rv_20d`（年化口径，主要对应 20D 窗口）
- GVZ 已除以 100 转为小数格式，与 fwd_rv_20d 单位对齐
- 正值表示 IV 高估（期权偏贵），负值表示 IV 低估（期权偏便宜）

**Phase 3 基线验证结论**：
- 波动率可预测性远高于收益率：rv IC (0.23-0.29) vs ret IC (0.07-0.21)
- GVZ 在所有任务中都是 top 特征（压倒性重要）
- 波动率聚集效应 (volatility clustering) 是核心驱动力

### 2.4 信号融合 (Signal Fusion)

三个模块的输出汇聚为统一信号向量：

```
regime_prob (bull/bear/mixed概率)
fair_value_q10 / q25 / q50 / q75 / q90 (公允价值条件分位数)
band_position (当前价格在区间中的相对位置, 0-1)
pred_rv_10d / pred_rv_20d (实现波动率预测)
iv_rv_spread (IV偏离度)
macro_regime (宏观Regime标签)
```

信号融合逻辑：
1. **Regime 决定交易方向约束**：Bull regime 以做多为主，Bear regime 不做多，Mixed 缩仓
2. **Band position 决定入场时机**：价格在 q10 附近 = 低估入场，q90 附近 = 高估离场
3. **波动率/IV 决定期权结构**：IV 不贵用单腿，IV 偏贵用价差

该信号向量作为期权策略层的输入。

## 三、期权策略层

### 3.1 策略类型（当前阶段）

本金较小，聚焦三类策略：

| 信号组合 | 策略 | 适用场景 |
|----------|------|----------|
| 强烈看涨/看跌 + IV 不贵 | 买单腿 Call/Put | 方向明确，期权价格合理 |
| 横盘/微弱方向倾向 | 卖垂直价差 (Credit Spread) | 保证金低，适合小本金，赚 Theta+IV 回落 |
| 预期波动率大幅变化 | 波动率交易 | 买/卖 Straddle/Strangle |

### 3.2 策略选择逻辑

```
方向强 + IV低  ->  买单腿期权（高杠杆博方向）
方向强 + IV高  ->  Debit Spread（降低IV风险）
方向弱 + IV高  ->  Credit Spread（赚IV回落 + Theta衰减）
方向不明 + 预期波动放大 + IV低  ->  买跨式
宏观月线看多  ->  禁止裸空Call，看空时只做小仓位 Put Spread
```

### 3.3 决策输出格式

每次信号生成需输出：
- 策略类型 + 方向
- 建议行权价范围
- 建议到期日（匹配预测时间窗口）
- 建议仓位（占总资金比例）
- 止损/止盈条件
- Greeks 暴露 (Delta / Vega / Theta)
- 预期胜率与风险回报比

### 3.4 V1 策略范围限制

第一版只做两类策略：
1. **单腿方向单** (买 Call / 买 Put)
2. **垂直价差** (Bull Call Spread / Bear Put Spread / Credit Spread)

跨式/宽跨式放到 V2。原因：波动率交易比方向交易更容易被 IV 曲面和买卖价差狠狠干碎。

## 四、基准策略 (Benchmark)

所有模型和策略的表现必须与基准对比，否则"模型有效"这句话没有参照物。

### 4.1 四个基准策略

| 基准 | 描述 | 意义 |
|------|------|------|
| **Buy & Hold GLD** | 全仓持有 GLD ETF | 最简单的黄金敞口，Alpha 的底线 |
| **简单趋势跟随** | 20/60 日均线交叉做多/做空 | 最基本的趋势策略，衡量方向预测的增量价值 |
| **固定 Delta 滚动期权** | 每月买入固定 0.30 delta 的 30DTE call/put，持有至到期 | 衡量期权策略选择的增量价值 |
| **IV 分位数策略** | IV 在历史 20% 分位以下买跨式，80% 分位以上卖跨式 | 衡量波动率预测的增量价值 |

### 4.2 基准操作规则（防止基准被写成木头人）

- **开仓日**：每月第一个交易日
- **到期日选择**：最接近 30 DTE 的月度到期日
- **成交价**：mid + 25% bid-ask spread（中性假设）
- **平仓规则**：到期前 5 个交易日强制平仓
- **信号缺失**：空仓（不强制入场）
- **手续费/滑点**：与策略回测使用相同假设

### 4.3 评估指标

- 年化收益率 / 最大回撤 / Sharpe Ratio / Sortino Ratio
- 胜率 / 盈亏比
- 月度收益分布 / 最大连续亏损次数
- 相对基准的超额收益与信息比率

## 五、风险管理与仓位纪律

### 5.1 硬性规则（不可覆盖）

| 规则 | 限制 |
|------|------|
| 单笔最大亏损 | 不超过净值的 **3%** |
| 单日总 Delta 暴露 | 不超过净值的 **20%** (等价 GLD 股数) |
| 单日总 Vega 暴露 | 不超过净值的 **5%** |
| 单日总 Theta 暴露 | 控制在净值的 **-1%** 以内 |
| 事件周仓位折扣 | FOMC/CPI/NFP 发布前 2 天，新仓位减半 |
| 连续亏损降杠杆 | 连续 3 笔亏损后，下一笔仓位降至正常的 50% |
| 近到期合约禁入 | DTE < 3 天禁止新建仓位（Gamma 风险过大） |

### 5.2 组合层约束

| 规则 | 限制 |
|------|------|
| 同方向同期限最大持仓 | 不超过 3 笔 |
| 单一 expiry 风险集中度 | 不超过总 Delta/Vega 的 50% |
| 单一事件窗口总暴露 | 不超过正常水平的 50% |
| Pyramiding (信号叠加加仓) | V1 禁止，同方向不追加 |

### 5.3 执行约束（回测与实盘均适用）

| 约束 | 阈值 | 说明 |
|------|------|------|
| 最小 OI | >= 100 | 流动性过滤 |
| 最小当日成交量 | >= 50 | 避免僵尸合约 |
| 最大 bid-ask spread | <= $0.20 或 <= 10% mid | 滑点控制 |
| DTE 范围 | 7 ~ 90 天 | 避免极短期(Gamma爆炸)和极长期(资金效率低) |
| 禁止极端深虚值 | Delta 绝对值 >= 0.05 | 深虚值流动性差，胜率极低 |
| 手续费假设 | $0.65/合约 | 回测中必须扣除 |
| 滑点假设 | 0.5 * bid-ask spread | 回测中必须加入 |
| 美式期权提前指派 | ITM 且 DTE < 7 天时标记风险 | 需要额外监控 |

## 六、后续改进方向

基于 Phase 3 基线结果，优先级排序：

| 方向 | 优先级 | 预期收益 | 依据 |
|------|--------|---------|------|
| Regime 切换模型 | 高 | 解决 2024+ Ridge 失效问题 | 基线 L/S 信号在 regime shift 时崩溃 |
| GARCH 波动率基线 | 高 | 与 ML 基线对比，验证波动率预测增量 | rv IC 已达 0.25-0.29，有基础 |
| 宏观 release-date 严格对齐 | 高 | 消除潜在前视偏差 | 当前用 ffill，可能泄漏未来信息 |
| 方向标签转 2 分类 | 中 | 提升方向信号纯度 | 3 分类准确率仅 34-39% |
| 尾部事件类别平衡 | 中 | 改善尾部检测召回率 | XGBoost 86.7% < majority 88.5% |
| 特征选择 (LASSO/mutual info) | 中 | 减少噪声特征，提升稳定性 | 116 特征对 ~3700 样本可能过多 |
| LSTM/TFT 深度学习 | 低(V2) | 捕捉非线性时序依赖 | 需先验证基线+regime足够强 |
| 跨式/波动率策略 | 低(V2) | 扩展策略空间 | 需先建好波动率预测模块 |
