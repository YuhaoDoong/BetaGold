# Regime 分类器详细分析

## 分类方法

规则打分 (非ML), 7个宏观因子:
- 实际利率变化、美元指数变化、通胀预期、央行购金
- 波动率分位数、持仓变化、动量
- 每因子 +1(Bull)/0(Mixed)/-1(Bear) 打分
- EMA(20) 平滑总分, 阈值划分 Bull/Mixed/Bear
- min_hold_days=20 防止频繁切换

### 假阳性年份分析

- **2012**: 黄金见顶后横盘, Regime因通胀+央行购金误判为Bull
- **2022**: 俄乌战争初期短暂Bull(48天), 随后加息周期导致金价下跌
- **2023**: 仅4天Bull, 影响极小

整体假阳性率: 3/15 Bull年份 = 20%, 但严重假阳性(2022)仅1次

## 对 Phase 4B 的意义

1. **Bull regime 可靠**, 5d/10d/20d均显著优于Non-Bull
2. **假阳性偶发**, 主要在 regime 转折年份(2012/2022)
3. **Bull段稳定长期**, 中位102天, 适合多次交易
4. **Bull退出是强信号**, 退出后20天70%下跌 — 可用于关闭期权仓位
5. **潜在改进**: 用DL学习regime分类, 可能减少假阳性 (待验证)
